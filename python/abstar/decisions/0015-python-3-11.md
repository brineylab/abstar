# 0015: Python >= 3.11

## Status

Accepted (2026-11-20)

## Context

The package needs a minimum Python version. Python 3.10 reached end of life in October 2026.

## Decision

The package requires Python 3.11 or newer. This was a call made in the design. Dependency versions follow the project rule of lower bounds only, unless a known incompatibility forces a cap.

## Alternatives considered

- Keep supporting 3.10: end of life, so not worth the cost.

## Consequences

- Newer language and library features are available.
- Users on 3.10 or older cannot install the new version.
